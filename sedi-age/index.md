# SEDI Age

The state issues this aggregate credential to the citizen. Its `A` section holds an issuee block, issued and expiration date blocks, and blinded boolean blocks for thresholds 13, 14, 15, 16, 18, 21, 40, 62, 65, 67 and 70. The holder can disclose the over-21 block without disclosing a birth date. Its required `coreIdentity` edge links to Core, and an optional `utahAgent` edge links to an authorizing agent credential. This is [Sam Smith's Age schema at keripy `927c0cb8`](https://github.com/WebOfTrust/keripy/blob/927c0cb8/tests/sedi/test_sedi.py#L1244-L1645), reproduced byte for byte with SAID `EPqXrwPT6b0_KghrrMuIdmuD68Aytv1XK6jU86EumgJV`; [his revision at `9a8b7aa7` and `80f77b73`](../sedi-age-pre-927c0cb8-0.1.0/), which lacked the `utahAgent` edge, remains resolvable. Sam Smith is the author. It replaces Bakobo's provisional profile, which is [archived as 3.0.0](../sedi-age-3.0.0/) and superseded.

[`example.json`](example.json) is Guy's Age from Sam's `test_sedi_acdcs` at `927c0cb8`, unmodified, whose `coreIdentity` edge carries `["E1E", "DI1I", "NI2I"]`; the Summit demo's own issued Age uses `["E1E", "NI2I"]`, the shape of Sam's Wyn Age vector, because `DI1I` has no implementation yet, as the summit's `this.i` records. [`examples/prove-over-21.json`](examples/prove-over-21.json) discloses only its issuee and over-21 blocks. [`invalid/`](invalid/) contains cases the schema refuses. Sam's schema does not pin `coreIdentity`'s far schema or the blocks' array positions, so a verifier checks the edge's schema SAID and the issuee binding with the protocol, not with JSON Schema validation alone. The corpus linter checks schema and outer SAIDs but does not recompute the AGID (tick `7v2h`). `this.i` `@3x2jtfxc` and `@6uxg0vj0` record the re-pins.
