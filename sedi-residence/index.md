# SEDI Residence

The state issues Residence to the citizen as a separate credential, with independently disclosed street, city, county, state, postcode, country and issued-date blocks. Its required `coreIdentity` edge links to Core, and an optional `utahAgent` edge links to an authorizing agent credential. This is [Sam Smith's Residence schema at keripy `927c0cb8`](https://github.com/WebOfTrust/keripy/blob/927c0cb8/tests/sedi/test_sedi.py#L964-L1240), reproduced byte for byte with SAID `EH5hn7CbtDFxhS3IKioC8P-e4YyZoxqzhRpr4X_e32BD`; [his revision at `9a8b7aa7` and `80f77b73`](../sedi-residence-pre-927c0cb8-0.1.0/), which lacked the `utahAgent` edge, remains resolvable. Sam Smith is the author. Each attribute block is either an expanded object or its compact SAID string, so a holder can reveal one block, such as county, while withholding the others. The `coreIdentity` edge has no compact arm, so the whole edge section is compacted or the edge stays expanded. Sam dropped the expiration date that his earlier revision carried. Bakobo's [0.2.0 amendment](../sedi-residence-0.2.0/) and Sam's [0.1.0 at `ec307cd74`](../sedi-residence-0.1.0/) remain resolvable. A verifier must resolve and verify compact references before using their claims.

[`example.json`](example.json) is Guy's Residence from Sam's `test_sedi_acdcs` at `927c0cb8`, unmodified; Sam's vector omits the optional `a.rd` and the optional `utahAgent` edge, and its `coreIdentity` edge carries `["E1E", "DI1I", "NI2I"]`. The Summit demo's own issued Residence uses `["E1E", "NI2I"]`, the shape of Sam's Wyn Age vector, because `DI1I` has no implementation yet; the summit's `this.i` records that decision. [`invalid/`](invalid/) holds negative cases. `this.i` `@3x2jtfxc` and `@6uxg0vj0` record the re-pins.
