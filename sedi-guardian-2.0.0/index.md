# SEDI Guardian 2.0.0 (archived)

This is the immutable 2.0.0 schema retained for SAID resolution. It named the ward by an outgoing `subject` edge and used `powers` for coarse scope. New issuance uses [version 3.0.0](../sedi-guardian/), which follows the ward placement in Sam Smith's #1550 discussion. The archived schema is a historical Bakobo profile, not Sam's schema.

Its original [governance rules](rules.json) remain available under SAID `EOW7nnASAYoY72gJ7brJwE0V2Hm8o6RfZvN2gNeyKmO0`. The schema's historical description names the former current rules path; the schema bytes and SAID are preserved.
