# SEDI Residence

The state issues Residence to the citizen as a separate credential, with independently disclosed street, city, county, state, postcode, country and issued-date blocks. Its required `coreIdentity` edge links to Core with `E1E` and `NI2I`. This is [Sam Smith's Residence schema at keripy `9a8b7aa7`](https://github.com/WebOfTrust/keripy/blob/9a8b7aa7/tests/sedi/test_sedi.py#L1100-L1362), reproduced byte for byte with SAID `EH7ayivQLHwfBKwFhg7mcpOzHEWcvvJ24EO0OyzvPVKQ`. Sam Smith is the author. Each attribute block is either an expanded object or its compact SAID string, so a holder can reveal one block, such as county, while withholding the others. The `coreIdentity` edge has no compact arm, so the whole edge section is compacted or the edge stays expanded. Sam dropped the expiration date that his earlier revision carried. Bakobo's [0.2.0 amendment](../sedi-residence-0.2.0/) and Sam's [0.1.0 at `ec307cd74`](../sedi-residence-0.1.0/) remain resolvable. A verifier must resolve and verify compact references before using their claims.

[`example.json`](example.json) is Guy's Residence from Sam's `test_sedi_acdcs` at `80f77b73`, unmodified (the schema is unchanged since `9a8b7aa7`); Sam's vector omits the optional `a.rd`. [`invalid/`](invalid/) holds negative cases. `this.i` `@3x2jtfxc` records the re-pin.
