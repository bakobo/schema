# SEDI Residence 0.1.0

This is Sam Smith's original [SEDI Residence schema at `ec307cd74`](https://github.com/WebOfTrust/keripy/blob/ec307cd74/tests/sedi/test_sedi.py#L361-L588), preserved byte for byte with SAID `EEgFNN1XH90koG5J5pbXKlRNU6TnibizaTQmJcRfEcop`. It accepts expanded nested blocks only. Bakobo's [0.2.0 amendment](../sedi-residence-0.2.0/) added compact SAID-string representations, and [Sam's current revision](../sedi-residence/) adopted them.
