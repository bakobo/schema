# SEDI Core Identity

The state issues Core to the citizen. Its individually disclosed blocks are given name, middle name, family name, name suffix, birth date, facial image proof, legal presence status, and issuance and expiration dates; a required boolean `primary` is true only on the management copy issued to the SEDI Management AID and false on bulk-issued copies. Its required `utahAgent` edge links the issuing department to an authorizing agent credential, and an optional `guardians` edge group, an m-ary operator over up to four guardian edges (`first` to `fourth`), links a ward's Core to the guardianship credentials that name the ward. This is [Sam Smith's Core schema at keripy `80f77b73`](https://github.com/WebOfTrust/keripy/blob/80f77b73/tests/sedi/test_sedi.py#L528-L901), the Summit's frozen pin, reproduced byte for byte with SAID `ECxPtf9IpBUT1pRZK4eaLA8O2jlc1oXYioYjcHo09eUC`; [his `9a8b7aa7` revision](../sedi-core-pre-guardians-0.1.0/), which lacked the group, remains resolvable. Sam Smith is the author. Each attribute block is either an expanded object or its compact SAID string, which is the partial-disclosure fix Bakobo's [0.2.0 amendment](../sedi-core-0.2.0/) anticipated. Sam's schema leaves the group's operator and each member's far schema and operator as free strings, and makes the group optional, so a verifier must hold the group to `AND` or `OR` and each member to the guardianship schema and `NI2I`, and a ward authorization's `authority` to a guardianship the subject Core's group names; heti does both. The `utahAgent` edge has no compact arm, so an issuer or holder compacts the whole edge section or keeps the edge expanded. [Version 0.1.0](../sedi-core-0.1.0/) preserves Sam's earlier schema at `ec307cd74`. A verifier must resolve and verify compact references before using their claims.

**Legal presence status is endorsed.** Sam Smith confirmed in an email to Daniel Hardman on 2026-09-23 that `legalPresenceStatus` is an endorsed status, not only an input to proofing. The State plans visitor SEDIs, for example for Olympics visitors and out-of-state hunting licence holders, whose statuses are other than citizen. The values are still to be decided, so the schema keeps the field a free string. Utah Code [63A-20-301(2)(f)](https://le.utah.gov/xcode/Title63A/Chapter20/63A-20-S301.html) names name, birth date, image, and Utah residence address as endorsed attributes.
